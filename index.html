How NKS-94 Works

NKS-94 assigns every supported character a value from 1 to 94.

The alphabet is ordered as lowercase letters, uppercase letters, numbers, symbols on the number keys, and then the remaining keyboard symbols.

When encoding, the value of the next plaintext character is added to the current character's value. If the result goes above 94, it wraps around to 1.

The final character is unchanged because there is no character after it.

Decoding works backwards from the final character, subtracting the value of the next plaintext character.
