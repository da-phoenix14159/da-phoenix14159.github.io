How NKS-94 Works

NKS-94 assigns every supported character a value from 1 to 94.

The alphabet is arranged in the following order: lowercase letters, uppercase letters, numbers, symbols on the number keys, and then the remaining keyboard symbols.

When encoding, each character is combined with the value of the character immediately after it. The final character remains unchanged.

If a value goes above the highest active value, it wraps around to the beginning of the alphabet.

Decoding works backwards from the final character.
